# தாய் பவுண்டேஷன் (Thaai Foundation) — Website

போதை மறுவாழ்வு மையம், அருப்புக்கோட்டை (Drug De-addiction & Rehabilitation Center, Aruppukkottai) — official informational website.

## About

A single-page static website for Thaai Foundation, a drug de-addiction and rehabilitation center based in Aruppukkottai, Tamil Nadu. The site is built with plain HTML/CSS (no build step or framework dependencies).

## Tech Stack

- HTML5 + CSS3 (single file: `index.html`)
- Google Fonts / jsDelivr CDN (`Noto Sans Tamil`, `Inter`)

## Local Development

No build tools required — just open `index.html` in a browser, or serve it locally:

```bash
npx serve .
```

## Deployment

Deployed on [Vercel](https://vercel.com).

**Live site:** [https://taai-foundation-website.vercel.app](https://taai-foundation-website.vercel.app)
